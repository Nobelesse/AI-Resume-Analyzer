# Version 1.5.8.1 — ATS Report & Chart Stability Hotfix

- Removes the expandable interactive bar chart from the Advanced ATS page to avoid the browser's fullscreen chart toolbar loop.
- Uses six stable progress bars showing exact awarded/max points, without fullscreen UI.
- Provides a dedicated full PDF assessment report from the same readiness and job evidence shown on screen.
- Reports missing job description as **Not assessed** and unscorable job descriptions as **Not scored**, not as zero.
- Keeps the limitations explicit: this is a transparent heuristic and not a vendor ATS certification.
- Does not change readiness weights, skill extraction, the job-compatibility model or previous saved user data.
