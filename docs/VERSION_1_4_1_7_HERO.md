# Version 1.4.1.7 — Hero Motion and Realism Polish

This release keeps the successful 1.4.1.6 hero framing while improving motion and realism: more breathing room between the copy and the orbiting sphere, slightly faster and smoother rotation, stronger cursor-driven 3D response, and a more cinematic starfield with fewer oversized sparkle crosses and more realistic twinkling. Backend features, authentication, SQLite data, O*NET integration, ATS analysis and Ollama support remain unchanged.
