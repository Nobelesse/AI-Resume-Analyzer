# Version 1.4.2.3 — Orbit Continuity & Smooth 3D Fix

This release corrects visible breaks in the cinematic hero orbit lines. Orbit rendering now extracts continuous front and back ranges before stroking them, which removes harsh restart artifacts while preserving 3D front/back depth. Orbit accent strokes were softened and refined to reduce line fragmentation. Sphere depth, layout, and dark abyss styling remain intact.
