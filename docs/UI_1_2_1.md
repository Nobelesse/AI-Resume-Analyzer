# UI 1.2.1 — Integrated 3D intelligence hero

The homepage displays a single full-width, live canvas hero with the heading rendered above its animation inside the same first-party Streamlit component. The network mesh uses 3D coordinates for connection calculation and screen coordinates for rendering. Decorative visual only; protected navigation remains handled by Streamlit.

Use `python -m streamlit run app/main.py`. This update does not touch stored resumes, accounts or Ollama settings.
