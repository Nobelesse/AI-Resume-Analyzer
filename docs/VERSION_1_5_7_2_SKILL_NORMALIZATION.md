- Resolves explicit resume abbreviations HTML, CSS and MS Word to official O*NET technology names.
- Leaves customer service, communication and bookkeeping as distinct soft/general skills, not software proficiency.
- Does not mutate or require re-importing the existing private O*NET database.
- Adds read-only per-analysis O*NET retrieval/filter/fallback diagnostics.
- Preserves conservative thresholds so generic overlaps cannot produce unrelated recommendations.
- O*NET software examples are NOT universal required skills, and career rankings remain heuristics.
