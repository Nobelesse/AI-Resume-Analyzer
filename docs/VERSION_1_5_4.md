# Version 1.5.4 — Occupation Evidence Scoring

Career rankings now prioritize actual occupation-specific skill overlap; domain alignment is a bounded 12-point contribution. Individual breakdowns are shown on the Career Finder page. Rankings remain heuristic and should not be interpreted as calibrated job suitability probabilities. Gemini remains opt-in for explanations; the page now indicates whether the API key is configured without sending any information to Google. No additional datasets are required for this release.
