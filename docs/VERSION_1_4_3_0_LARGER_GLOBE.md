# Version 1.4.3.0 — Larger Globe and Orbits

Desktop layout scales the entire globe-and-orbit composition up, without changing orbit radii relative to the globe (1.278 and 1.398) or the Dark Abyss theme. An expanded desktop frame changes the center from 76.5% to 75.5%, orbit fitting bounds from 2.08 to 1.90 and height ceiling from 0.376 to 0.430. Mobile fitting retains a conservative horizontal bound and allows a slightly higher height ceiling. The existing 30 FPS optimized closed-stroke renderer is unchanged.

Visual confirmation at the target screen size is recommended.
