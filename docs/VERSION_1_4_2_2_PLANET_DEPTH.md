# Version 1.4.2.2 — Planet Depth & Orbit Perspective Polish

This release refines the cinematic hero only. The sphere now has stronger atmospheric depth, richer inner shading, and softer haze for a more planet-like feel. Orbit rendering is split into back and front layers so rear arcs are dimmer and softer while front arcs are brighter, sharper, and more dimensional. The rest of the AI-Resume-Analyzer application remains unchanged.
