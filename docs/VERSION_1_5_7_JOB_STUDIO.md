# Version 1.5.7 — Advanced Job Studio

Job Studio now shows line-level required/preferred requirements, exact detected and undetected skill evidence, unverified non-skill requirements, and cautious resume-improvement ideas. This is an offline heuristic, not an actual recruitment decision or an employer ATS score. A missing mention is not proof of lacking a skill.

Existing user account databases, resumes, O*NET imports and secrets are intentionally excluded from release archives.
