# Version 1.4.1.3 — Cinematic background hero

This UI-only release uses the existing self-contained Canvas scene. The homepage hero is 650 px tall and full width of Streamlit’s content column; it does not cover the sidebar or browser viewport. Text is positioned over a larger, denser 3D-projected violet/blue wireframe sphere. A directional overlay protects text contrast, with compact mobile layout. The animation pauses on hidden tabs, caps its drawing rate around 30 frames per second, and respects reduced-motion settings. No remote JS dependencies.

The guest card-to-info-banner 20 px spacing from Version 1.4.1.2 is preserved. Back up local data before merging. User data, taxonomy tables, Ollama and auth services have not been changed.
