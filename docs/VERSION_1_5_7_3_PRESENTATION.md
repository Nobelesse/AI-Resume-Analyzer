# Version 1.5.7.3 — Clean Career Finder

Presentation-only update to the **Career Finder page**. The career scoring, O*NET occupation matching, diagnostics returned by the service, and saved resume access remain intact. The student-facing UI does not display data-source names, technical counters, ranking internals or provider controls. No provider is silently contacted. The application continues offline by default; optional cloud guidance is no longer surfaced on this page. Career evidence and optional learning topics remain visible, with appropriate qualification disclaimers.

The updated design retains the shared Dark Abyss + Gold style. Other pages are left unchanged in this release.
